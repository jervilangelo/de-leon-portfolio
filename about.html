About me

I'm Jervil Angelo De Leon, an all-round IT professional based in Makati: programmer, game developer, video editor and helpdesk support, with a BSIT from FEU Institute of Technology.

I currently work in helpdesk support on an HRIS project, giving Level 1 support for an HR system used by seafarers and office staff. I resolve what I can, escalate what needs it, and document fixes so the same problem only gets solved once. That work is where my template tracker automation came from.

My path into IT went through animation and game development, a C# programming internship, and onsite hardware work for an HP service centre. Each stage added something I still use: programming, hands-on troubleshooting, and explaining a fix to the person who depends on it.

I'm working toward a role as a Cloud Engineer. My approach is to earn a certification, then build something real with it on AWS: a serverless ticketing API, a secured EC2 setup in a custom VPC, and Teolohiya.site, which is live today.
